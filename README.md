# Sobre Mim

Página pessoal de **João Pedro Vaz Garbin** — estudante de Engenharia de Software e desenvolvedor backend em formação.

## 📋 Sobre o Projeto

Esta é uma página pessoal simples, moderna e acessível, desenvolvida com **HTML5** e **CSS3** puros, seguindo boas práticas de:

- **Clean Code** — código organizado, legível e fácil de manter
- **Acessibilidade** — HTML semântico, contraste adequado, navegação por teclado
- **Responsividade** — layout adaptável do mobile ao desktop
- **Performance** — sem dependências JavaScript, apenas uma fonte externa (Space Grotesk)

## 🎯 Conteúdo

- **Hero/Apresentação** — nome e tagline profissional
- **Seção "Sobre"** — formação, foco backend e objetivos profissionais
- **Tech Stack** — tecnologias estudadas organizadas por categoria (Backend, Bancos de Dados, Frontend, DevOps/Cloud, Testes) com níveis de conhecimento prudentes
- **Projetos** — quatro projetos com descrição, tecnologias e links para repositórios
- **Tecnologias para aprofundar** — três tecnologias alinhadas ao perfil backend (Kubernetes, AWS, Microsserviços)
- **Contato** — links funcionais para GitHub e LinkedIn (header e footer)

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 com Custom Properties (variáveis CSS)
- CSS Grid / Flexbox para layout
- Google Fonts (Space Grotesk)
- SVG inline para ícones

## 🚀 Como Visualizar

Abra `index.html` diretamente no navegador ou use um servidor local:

```bash
# Com Python
python -m http.server 8000

# Com Node.js (npx serve)
npx serve

# Com VS Code Live Server
# Clique com botão direito no index.html > "Open with Live Server"
```

## 🌐 Deploy

A página está pronta para publicação no **GitHub Pages**:

1. Push para o repositório `JpCode01/sobre-mim`
2. Em Settings > Pages, selecione a branch `main` e pasta `/ (root)`
3. Acesse em `https://jpcode01.github.io/sobre-mim/`
